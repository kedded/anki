# Recall

Anki-style flashcards in the browser. Import an Anki `.apkg`, study offline, nothing leaves the device.

**Deploy (GitHub Pages):** upload all files to a repo (root or a subfolder), enable Pages, open the URL.
On iPhone: Safari → Share → Add to Home Screen. Open it twice after an update (first open fetches the new version).

**Supports:** latest `.apkg` (zstd) and legacy `.apkg`; basic, reversed, cloze and type-answer cards; audio, images, card CSS;
nested decks; learning steps, daily limits, undo, streak.
**Not supported:** AnkiWeb sync, review-history import, add-ons, JavaScript inside card templates (blocked by design).
